# 🎓 المنصة الأكاديمية الرقمية للأستاذ الدكتور بن جلول مختار
### جامعة ابن خلدون تيارت — كلية الآداب واللغات — قسم اللغة والأدب العربي
**مخبر الدراسات النحوية واللغوية بين التراث والحداثة في الجزائر**

---

منصة تعليمية وبحثية جامعية متطورة مخصصة لتدريس مقاييس اللسانيات، الصرف، والنحو، مدعومة بوكلاء الذكاء الاصطناعي الأكاديمي، وخاصية التحميل والمزامنة السحابية عبر Google Drive، ونظام التسجيل والمتابعة عن بُعد للطلبة والأساتذة الباحثين.

---

## 🌟 الميزات الأكاديمية والتقنية للمنصة

### 1. 📁 التكامل مع Google Drive (تحميل المحاضرات والمطبوعات)
- **مجلدات سحابية موحدة**: زر مباشر في ترويسة كل مقياس ينقل الطلبة إلى مجلد Google Drive المخصص للمقياس.
- **روابط مباشرة لكل محاضرة**: كل محاضرة من المحاضرات الـ 14 مزودة بزر تحميل وقراءة مباشر من Google Drive.
- **إدارة المحاضرات للأستاذ**: نموذج رفع وتحديث المحاضرات يتيح إضافة أو تعديل رابط Google Drive لأي محاضرة بصيغة PDF أو Word أو العروض التقديمية.

### 2. 👥 نظام التسجيل والمتابعة عن بُعد (Remote Registration)
- **تسجيل طلبة ماستر 1**:
  - الشعبة: **الدراسات اللغوية** (ثابتة وفق الهيكل الرسمي).
  - التخصص: **لسانيات الخطاب** (ثابت).
  - الفوج: الاختيار بين **الفوج 1، الفوج 2، الفوج 3**.
- **تسجيل طلبة السنة الثانية ليسانس**:
  - الشعبة: الاختيار بين **الشعبة الأدبية** أو **الشعبة النقدية**.
  - الفوج: الاختيار بين **الأفواج 1 إلى 6**.
- **تسجيل الأساتذة والباحثين**:
  - الرتبة الأكاديمية، الجامعة، الكلية، القسم، التخصص الدقيق، ورقم التواصل.
- **حفظ السجلات وتصديرها**:
  - تُحفظ بيانات المسجلين تلقائياً في المتصفح (`localStorage`).
  - يمكن للأستاذ تصدير قائمة الطلبة المسجلين بجميع بياناتهم وأفواجهم مباشرة إلى ملف **Excel / CSV** بنقرة زر واحدة.

### 3. 📚 المنهج الدراسي المعتمد (14 محاضرة رسمية لكل مقياس)
1. **مقياس اللسانيات العربية** (ماستر 1 — دراسات لغوية — لسانيات الخطاب): 14 محاضرة كاملة تغطي من نشأة اللسانيات ونظريات الخطاب إلى التداولية وحوسبة اللغة.
2. **مقياس الصرف العربي** (السنة الثانية ليسانس — السداسي الأول): 14 محاضرة مفصلة في الميزان الصرفي، بنية الأفعال، الإعلال والإبدال، والاشتقاق.
3. **مقياس النحو العربي** (السنة الثانية ليسانس — السداسي الثاني): 14 محاضرة شاملة لنظرية العامل، النواسخ، المفاعيل، وأساليب الجملة المركبة.

### 4. 🤖 استوديو وكلاء الذكاء الاصطناعي (AI Academic Agents)
- **الوكيل اللساني والمشرف الأكاديمي**: يجيب على استفسارات الطلبة وفق الشواهد اللغوية والنحوية التراثية والحديثة.
- **مصحح الواجبات الذكي**: يقدم تغذية راجعة آلية وملاحظات توجيهية لإجابات الطلبة.

## 🚀 كيفية إدراج المنصة في GitHub ورفعها على الإنترنت

### أولاً: إنشاء مستودع جديد على GitHub
1. افتح حسابك على [GitHub](https://github.com) واضغط على زر **New repository**.
2. اختر اسماً للمستودع (مثال: `univ-bendjelloul-platform` أو `academiq-bendjelloul`).
3. اجعل المستودع **Public** أو **Private** (حسب رغبتك) ولا تقم بوضع علامة على Initialize with README (لأن المشروع جاهز بالفعل).
4. اضغط **Create repository**.

### ثانياً: ربط ورفع المشروع من جهازك
افتح موجه الأوامر (PowerShell أو Terminal) داخل مجلد المشروع ونفّذ الأوامر التالية:

```bash
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git branch -M main
git push -u origin main
```
*(استبدل `USERNAME` باسم حسابك على GitHub و `REPO_NAME` باسم المستودع الذي أنشأته)*

## 🌐 كيفية نشر المنصة على الإنترنت مجاناً (إتاحة التسجيل والتحميل عن بُعد 24/7)

لكي يتمكن طلبتك وزملاؤك الأساتذة في أي ولاية بالجزائر من فتح المنصة والتسجيل وتحميل المحاضرات:
1. توجّه إلى موقع [Vercel](https://vercel.com) وسجّل الدخول بحساب GitHub الخاص بك.
2. اضغط على **Add New...** ثم **Project**.
3. اختر مستودع المشروع من القائمة (مثال: `univ-bendjelloul-platform`) واضغط **Import**.
4. اضغط زر **Deploy** دون أي تعديل في الإعدادات.
5. في غضون دقيقة واحدة، ستحصل على رابط عالمي دائم وآمن مجاناً مثل:
   `https://univ-bendjelloul.vercel.app`
   يمكنك إرساله للطلبة لنشره على مجموعات الدفعة، ومشاركته مع إدارة القسم والكلية ومخبر الدراسات النحوية واللغوية.
